
Student Marks Calculator 
📊

A simple Python project that calculates a student's total marks and percentage.

Features

- Takes student's name
- Takes marks of three subjects
- Calculates total marks
- Calculates percentage

Technology Used

- Python 🐍

How to Run

Run the "main.py" file using a Python compiler or Python environment.

Example

Student Name: Anirudh
Total Marks: 270
Percentage: 90.0%
